# Teaching fixture

`row_swap_system.json` is an original, deliberately constructed two-equation
teaching example. It is not observed financial, scientific, or learner data.

The equations are `2*y = 4` and `x + 3*y = 5`. Their unique exact solution is
`x = -1, y = 2`. The first coefficient is zero, so elimination must exchange the
rows before using the first pivot. Substitution gives residual `[0, 0]`.
