# Changelog

## 0.1.0 - 2026-11-02

First public educational release.

- Dependency-free, typed partial-pivot Gaussian elimination for finite square
  systems of dimension 1–256, with copied inputs and immutable results.
- Explicit scale-aware pivot rejection, residual and relative backward-error
  diagnostics, and documented conditioning and representation limitations.
- Bounded UTF-8 JSON input and atomic versioned JSON report output.
- Constructed row-swap fixture, independently worked tutorial, executed report
  and optional two-line intersection figure.
- Exact-rational and property-based checks, failure-path tests, strict typing,
  locked development dependencies and pinned CI actions.

The pre-1.0 API may evolve. This release does not establish learner validation,
production adoption, numerical certification or suitability for a particular use.
